# Power Pong Game

Power Pong is a two-player arcade-style game developed using HTML, CSS, and JavaScript.

## Controls

- Player 1: W / S
- Player 2: Arrow Up / Arrow Down
- Space: Start Game
- R: Restart Game

## Features

- Two-player gameplay
- Score system
- Power-ups
- Increasing ball speed
- Countdown after scoring
- Game over screen
